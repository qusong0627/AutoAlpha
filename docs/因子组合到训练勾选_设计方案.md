# 因子组合 → 训练勾选 设计方案

> 目标：把因子深度体检的结论变成**训练页开箱即用的勾选集合** ——
> 「报告里选出有用因子」→「训练页这些因子已经默认勾上」→ 直接开跑。

---

## 一、链路总览

```
因子深度体检（factor_deep_dive.py）
    │  A 衰减 / B 中性化 / C 扣费净收益 / D 拥挤 / E 组合构建 / F 可交易性
    ▼
推荐因子集 JSON（factor_portfolio.json，落数据集 report/ 目录）
    │  含：入选因子、方向、权重、口径、生成时间、淘汰理由
    ▼
写训练因子目录（apply_factor_selection_to_catalog.py）
    │  克隆已发布版本 → 命中因子 default_selected=true（其余 false）→ 发布
    ▼
训练页（ModelTrainingPage → FeatureSelector）
    │  目录的 default_selected 是勾选初值的 truth source（trainingUtils.tsx:991）
    ▼
用户看到「这些因子已经勾好」→ 直接训练
```

**为什么走目录而不是训练任务参数**：训练页的勾选初值只认目录的 `default_selected`
（前端把 catalog 当 truth source；缺 flag 时回退硬编码 PRESET）。写目录才能让用户"打开就看见勾好"。

---

## 二、三项任务

### P1. 扣费净收益改用 T+20 口径（对齐 IC 峰位）
现状：C 段按 T+5 日频调仓算成本——但 A 段实测**几乎所有因子的 |IC| 峰值在 T+20**，
日频口径把成本放大了约 4 倍，结论偏悲观。
改法：
- 毛收益用 `ls_20`（T+20 多空价差）；
- 成本用「20 日调仓的换手」= 1 − ∏(1 − 日换手) ≈ 20 日日换手之和（上限 1），乘往返成本；
- 净收益按 (毛 − 成本) / 20 折算日均；同时**保留 T+5 口径列做对照**（两个都展示）。

### P2. 组合构建产物（`factor_portfolio.json`）
- 输入：快照（IC/ICIR/相关矩阵）+ 序列（逐日 IC、换手、ls_20）
- 规则（透明、可配置）：
  1. 硬门槛：扣费净收益（T+20）> 0、`|ICIR| ≥ 0.15`、覆盖率 ≥ 60%
  2. 相关性去重：|ρ| ≥ 0.9 只留 |ICIR| 最大者（复用去重簇逻辑）
  3. 组合权重：最大 ICIR（收缩 Σ⁻¹μ，带方向符号）取 top-N；同时给等权/|IC| 加权作对照
- 产出字段：`dataset / generated_at / scheme / weights{name: w} / direction{name: ±1} /
  selected[] / rejected[]{name, reason} / expected{ic, icir} / source`
- 落盘：`<数据集>/report/factor_portfolio.json`（API 与训练侧都读它）

### P3. 页面「组合构建」面板
- 位置：因子报告页右上（与「因子去重」并列）→ 弹窗
- 内容：推荐因子集（权重条形 + 方向 + 入选理由）、对照三种方案、被淘汰因子与原因、
  「复制权重 JSON」按钮
- 数据：新增 `GET /api/v1/factor-report/portfolio?dataset=`

### P4. 写进训练目录并发布（勾选上）
`backend/scripts/apply_factor_selection_to_catalog.py`：
- 读 `factor_portfolio.json` → 克隆该数据集当前**已发布**目录为草稿（保留其它字段）
- 把入选因子的 `default_selected=true`，其余置 false（可 `--keep-others` 保留原样）
- 补 `enabled=true`；发布 → 训练页勾选即生效
- 幂等：重复执行只改 flag；`--dry-run` 预演

## 三、口径与边界

- **推荐集是"训练默认勾选"，不是强制**：用户可以取消勾选；训练镜像内还有一层自动筛选
  （`select_top_factors`：n_top=80、|IC|>0.01、ICIR>0.15、相关性 0.9），两层口径互补。
- **方向符号**：负向因子（如高波动/高换手端）在组合里带负权重；训练侧是特征入模，
  **不做符号翻转**——符号只用于"组合权重"这个分析量的计算，训练时保留原始值。
- **数据集要匹配**：目录按 `source_dataset` 区分（l1_factors / l2_factors / l1_l2_factors /
  alpha_library），推荐集也按数据集分别生成；训练页选哪个数据源就用哪套勾选。
- **时效**：推荐集随快照刷新，建议每次重建快照后重跑 P2/P4（约 1 分钟）。

## 四、验收

1. `factor_portfolio.json` 生成，字段完整、可复现（同参数两次结果一致）
2. 目录新版本发布成功：入选因子 `default_selected=true`（DB 抽查）
3. **训练页实测**：打开模型训练页 → 因子勾选数 = 推荐集大小，且勾中的正是推荐因子
4. 报告 PDF 里 C 段同时给出 T+5 与 T+20 两个口径
