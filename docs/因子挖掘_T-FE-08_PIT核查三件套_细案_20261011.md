### 2.3 停牌 ffill 口径 —— 三套系统三种口径，出货集有幻影行

以 000029.SZ（深深房A，2016-09-14 停牌 → **2020-11-09 复牌**，复牌首日 close 11.89）为例：

| 系统 | 停牌期间（2016-09-14 ~ 2020-11-06）行为 | 判定 |
|---|---|---|
| `daily_{unadjusted,forward,backward}` 原始面板 | 停牌日**无行**（仅真实成交日有行） | ✅ 正确 |
| qlib 缓存 `cn_data`（sz000029 close.day.bin 逐位读） | 停牌日 = **NaN**（2016-09-14 起全 NaN，复牌日有值） | ✅ 正确 |
| `features_daily` / `l1_factors` | **每个交易日都有行**：close=11.17 冻结（停牌前最后收盘）、volume_ma_3=22065514 冻结、`mom_ret_20d=0.0`、turn_1 陈旧 | ❌ 幻影行 |

- 幻影行来源：`valuation`分区对在册股票逐交易日供行（并购表车辆），features_daily =
  估值+技术合并表 → 停牌股在合并后拿到「有估值行、技术列 ffill/凝固」的整行。
- 抽样分区幻影行数（features_daily 行不在当日 daily_unadjusted 中）：
  2017-01-03 = **178** 行；2019-06-03 = 16；2021-09-01 = 6；2024-01-02 = 5；2026-06-30 = 17。
  全库总量需全量扫描（本审计交付）。
- 风险载荷：①训练/筛选把长期停牌股当「价格平稳、零动量」样本；②幻影行上的
  `future_return_*` 标签跨复牌跳空（若存在）；③截面排名被凝固值污染。
- 附带发现（同一扫描顺带计量，不作主判据）：
  - `features_daily` **不含北交所**（2026-09-30 raw 5572 只中 92xxxx 348 只仅在 raw，
    features_daily 全缺）——口径说明，非缺陷；
  - 2026-09-30 features_daily 行数（5224）< raw：0914 起该集本体有编排变化
    （与既有记忆「32 列断在 20260914」同期），审计按分区出表让它可见。

## 三、设计决策

### D1 落点与形态

- 新脚本：`backend/scripts/audit/audit_pit_trio.py`（入 `backend/scripts/audit/` 家族）。
- 子命令：`financial` / `delisted` / `suspension` / `all`（默认 all），`--out-dir` 默认
  `<quantdb 根>/../refs/pit_audit/`（即 `data/refs/pit_audit/`，data/ 为符号链接、gitignored）。
- 产出：`T-FE-08_pit_audit_YYYYMMDD.md`（人读）+ `.json`（机器读，带 `schema_version`）。
- **只读**：不写任何数据集，只读 parquet footer / 列投影。

### D2 唯一实现不复制（财务重算核）

三视图全部走 `repair_valuation_ttm._sum4_map` 同一核（跨脚本 import，先例 =
`repair_ttm_datasets.py`）：

- `PIT₁(D)` = `_sum4_map(inc, asof=上一交易日)`（公告日+1 交易日可用，保守口径）
- `PIT₀(D)` = `_sum4_map(inc, asof=D)`（公告当日即可用）
- `naive(D)` = `_sum4_map(inc, asof=2099-01-01)`（无视公告日、文件内全量最新版——
  与 `pit_financial.audit_naive` 的 naive 语义一致）
- 上一交易日从 `daily_unadjusted` 分区名序列取前驱（面板即日历，不引第二事实源）。

### D3 财务审计判据（financial）

- 样本日（默认，`--dates` 可覆写）：发布季窗口 `20260415 / 20260422 / 20260430 /
  20260715 / 20260722 / 20261009` + 窗口外基线 `20260515 / 20250930`（对照锚）。
- 全市场逐格（不做抽样——income 全量载入仅 ~30 万行，一次载入多日复用）：
  对 `valuation` 与 `features_daily` 的 `net_profit_ttm / revenue_ttm / pe_ttm / ps_ttm`
  逐格分类（rtol=1e-3，健康日实证偏差为 0，容差只留取整裕量）：

  | 标签 | 含义 |
  |---|---|
  | `match_pit1` | 与公告日+1 口径一致 —— 合规 |
  | `match_pit0_only` | 仅公告当日口径可解释 —— 同日可用（±1 交易日，报告披露不造红线） |
  | `match_naive_only` | **前瞻**：只有偷看未公告报告期才能解释 —— 缺陷 |
  | `diverged` | 三视图均不可解释（提供方公式/陈旧/损坏）—— 需人看 |
  | `missing` | 源侧不可算（新股/缺季报）—— 不计入比率分母 |

- 判别力口径：只对**判别日**（当日 `naive ≠ PIT₁` 的格）统计泄漏率；同日三视图相同
  的格单列「无判别力」计数，防止全体巨量稀释出假的 0.00%。
- 次级一致性：`pe_ttm == total_mv / net_profit_ttm`（与修复核同式，rtol 1e-3）逐格核对，
  捕捉损坏期同款「分子分母不同源」。

### D4 退市审计判据（delisted）

- 内置 fixture（数据表，非硬编码逻辑；每项带证据注），只收公开交易记录无歧义的案例：
  600401.SH@2019-06-03、300104.SZ@2019-06-03、002450.SZ@2019-06-03
  （每条含 delist 事实与探针日依据；后续可加项）。
- 每条 × 六载体（raw 三面板 / valuation / financial 文件 / qlib instruments 区间）
  出存在性矩阵。
- 结构判据：锚日集合差 `symbols(D_old) − symbols(D_new)`（锚日 `20180102 / 20190603 /
  20210104 / 20240102 / 20260930` 两两）。幸存者过滤器判定 =
  「全部 fixture 缺席 **且** 新旧锚日集合差恒为 0」→ `survivorship_filter=CONFIRMED`。
- 输出 `status: known_open`（结构性存量；修复=上游回补退市股历史，另行立项，见 §六）。

### D5 停牌审计判据（suspension）

- phantom 行 = 出货集当日行、其 symbol 不在当日 raw 面板（`daily_unadjusted`）中。
  实现：先分区级行数快比（parquet footer，廉价），不等才做 symbol 级 anti-join。
- 逐数据集（默认 `features_daily,l1_factors`；`--datasets` 可加 `valuation` 等）：
  `phantom_rows` 总量、涉及 `symbols` 数、Top-K 最长幻影跨度（symbol/起止/天数）。
- 冻结值抽验：对 Top-K 跨度，验证幻影行 close == 停牌前最后真实 close（ffill 实证）。
  **实施注（评审 HIGH-2 后）**：比较必须在**出货集自身复权基**内做（前一交易日
  *面板* close vs 幻影行）；raw 未复权 close 与面板是两套基（同日比值中位 ~1.31、
  仅 ~6% 落在 rtol 内），跨基比数会把正常冻结误判 not-frozen。raw close 只作
  `*_aux` 旁证列。
- 复牌缝检验：跨度 ≥ 5 交易日的复牌日 R，检查其前一交易日幻影行上的 1 日收益
  标签是否把复牌跳空记成「1 日可交易收益」。**实施注（评审 HIGH-1 后）**：标签列
  两代命名——features_daily ≤20260918 分区为 `return_1d`、≥20260921 为
  `future_return_1d`（两代单位均为 %），候选表须两代全收，否则检查对全部历史是
  死代码；跳空同样取面板基，新增 `label_vs_panel_jump_consistent` 旗标核对
  标签与面板跳空是否同基（标签/100 vs 跳空，rtol 内）。
- 对照行：同一 Top-K 跨度的 qlib bin 全 NaN（抽样读 bin + calendar）——证明两套
  派生系统口径不一致，责任段在 features_daily 系。
- 反向覆盖差（raw 有、出货集无）按分区计数入表（北交所与 0914 编排变化可见化）。

### D6 报告与退出码

- md 由纯函数渲染（可测）；json 含各子审计的原始计数与样例。
- 默认退出码 0（审计员语义：报告即交付）；`--fail-on {none,critical}` 供未来挂 CI
  （当前已知 critical=幸存者偏差为存量缺陷，挂门禁会导致恒红——台账记录该取舍）。

### D7 不做的事

- 不改任何数据；不触 PG/Redis；不回补退市股（需先与 QuantDB 提供方核实是否持有
  退市股历史）；不在本任务内改 features_daily 幻影行（修复动作在报告产出后单独决策）；
  BSE 口径差异不判缺陷。
