### 2.5 ★ 预研实测（2026-10-11，全部真实数据）

**表 C · 正交检验（是否为价格动量代理？——否）**

| 检验 | 结果 | 结论 |
|---|---|---|
| 对照：板块近 3 日涨幅 top（纯动量） | **−1.9bp ≈ 零** | 裸动量在板块层无预测力 |
| streak≥3 × 市场 20 日环境=上涨 | +26.4bp | 两环境均正 |
| streak≥3 × 市场 20 日环境=下跌 | +34.7bp | **非牛市 beta 放大** |
| streak≥3 ∧ 涨幅低（低调吸筹） | +30.4 pooled / **−0.45 日均（口径打架）** | 样本薄，不作主推 |
| streak≥3 ∧ 涨幅高（追涨确认） | +22.3 / +0.54 日均 | 弱，不作主推 |

**预研三大结论**（直接决定设计）：
1. **唯一过闸信号 = 板块资金延续（连续净流入 ≥k 日）**：方向在全部切分下一致为正，非动量代理、涨跌环境双正——但强度中等（日均 3.5–12bp）、2024 年为负（时效波动）——**上屏必须携带分年证据，不许只报全窗好数字**。
2. **个股层资金流裸信号全部否决**（IC≤0.01）——页面对个股不做资金流预测承诺，避免"长得像预测实则噪声"的数字占据注意力。
3. **裸净额大小不是信号**（板块层 IC≈0）——凡是"净额榜"，只作背景级；预测级只有延续条件。

## 3. 预测分级纪律（v2 核心原则）

页面上每一个数字都必须归入三级之一，视觉上可区分、语义上不越级：

| 级 | 含义 | 呈现 | 门槛 |
|---|------|------|------|
| **P 预测级** | 有实测证据的阶段收益信号 | 徽章带历史超额（bp）与样本 n；hover 展开证据卡（§6） | 全窗与分年方向、正交检验、n≥门槛（板块条件 n≥500）**三过**才上屏；未过的一律不进（含已否决清单公示） |
| **C 背景级** | 描述事实（净额/占比/贡献度/广度…） | 无徽章，中性色、从属排版；标题注明「描述」 | 不进任何排序主键、不写"预示/概率"字样 |
| **E 证据台** | 可审计的历史统计 | 独立面板（§6），每条 P 级标注可溯源 | 全窗口径 + 逐年 + 环境分层 + n 全展示 |

**红线**：不输出编造概率分；bp 级强度如实标注；2024 年负超额显式展示不隐藏；「历史超额」≠「未来收益」的免责声明常驻证据台。展示面禁买卖措辞（沿展示/执行面用词边界）。

## 4. 桑基 v2 规格（结构视图 + 命中可视化）

- 分层：L1 主体（主力/散户）→ L2 量级（超大/大/中/小）→ L3 板块（**行业二级默认**，可切一级/概念；流入 Top6 + 流出 Top4）→ L4 每板块主力净额 TopK 个股（默认 5，可 3/5/10）。
- **双向的表达**：ECharts sankey 为 DAG 不可成环——不硬凹。符号双向（value=|净额| 渲宽，红=净流入/绿=净流出，全部/仅流入/仅流出 chips）+ 交互双向（板块⇄个股三面联动，§5）。
- **预测痕迹（P 级）**：仅板块节点携带——「连N」streak 徽章 + hover 证据卡（该状态历史 fwd1/3/5 超额与 n，引用 §6 证据表）。个股节点**不设**预测徽章（实测否决），只标净额与板块内 rank（C 级）。
- 多周期 1/3/5/10/20d 真实窗口求和（归一后）；节点/边带 `net`（真值）+ `sign` + `kind` + `key` 供联动；hover 高亮相邻路径。

## 5. 板块⇄个股 双向联动（工作台）

- **左 master（板块榜）**：**默认排序 = 延续状态驱动**（streak≥3 命中在前，同级按净额）——不按裸净额排（§2.5 结论 3）。行 = 排位 + 名称 + 双向净额条（C）+ 净额比（C）+ 连N 徽章（P）+ 命中条件历史超额徽章（P，hover 证据卡）+ 成分数。
- **右 detail（成分股）**：净额 / 贡献度% / 板块内 rank（C 级背景列）/ 涨跌幅；行点击 → 个股详情卡。
- **个股详情卡（R3 核心）**：
  - 20 日逐日五档序列（C）；
  - **所属板块归因**：板块 chips + 该股在各板块的贡献排名；点 chip 回板块视角（=「个股资金流返回板块」）；
  - **个股预测锚（P3）**：对接因子概率板 members 伴生件（个股 composite / model_rank / quadrant 已在库）→ 个股区显示「因子板共振态」；**个股层不出现资金流预测徽章**（实测否决，此句写进 UI 说明文案，用户能看见为什么）。
- 状态失配门：切周期/体系/日期清空选中（沿用因子板 membersKey 模式）。

## 6. 预测证据台（R4 的骨架，取代 v1「延续性研究」）

**布局（资金流全景页下半区，全宽）**：
1. **命中榜（今日）**：当日 streak≥k 命中的板块列表，每行 = 板块 + 连N + **该状态历史超额徽章**（全窗 bp + 分年三格微条 + n）+ 净额（C）。点击 → 桑基/工作台聚焦。这是「更大概率还会延续」的正面回答：不是图上画趋势线，而是「该状态在此前 520 个交易日中的条件超额是多少」。
2. **证据表（信号档案）**：预研全部信号一张表——过闸的（板块 streak≥2/3/5 × fwd1/3/5）给全部统计（n、全窗/日均超额、hit、逐年、环境分层）；**已检验未通过的（个股净额比/z20/背离/个股 streak/纯动量）单列一节「已实测、不具预测力、不参与展示」**——可审计、防误用。
3. **口径与披露条**（常驻）：样本窗、口径（可执行 T+1 建仓）、板块=当前成分回溯、bp 级强度、历史≠未来。

**builder 落数口径**：主口径改**可执行版**（信号 t 日盘后可得 → close(t+1)→close(t+4)），探针 t→t+3 口径保留为对照列（两列都上屏，防"漂亮口径"疑虑）。

## 12. 口径与风险披露（进 UI meta + 证据台）

1. 板块 = **当前成分回溯**聚合（survivorship 披露）；行业二级覆盖 79.5% 个股；
2. 证据主口径 = 可执行版 T+1 收盘建仓（对照列保留 t→t+3）；均为 qfq；
3. 2024 年板块 streak 超额为负——**时效波动是事实，不隐藏**；bp 级强度（日均 3.5–12bp）；「历史超额 ≠ 未来收益」；
4. 个股层资金流无预测力（IC≤0.01 实测）——页面明示，个体预测以模型/因子板为准；
