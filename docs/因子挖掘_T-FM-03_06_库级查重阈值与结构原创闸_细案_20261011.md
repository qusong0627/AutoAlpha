## 3. 设计

### 3.1 三层闸分工（阈值对表见 §4）

1. **批内 0.9/0.8（不动）**：统计派候选池是固定目录（32 key），批内去重防同批席位重复；
   台账明确「批内 0.9 保留」。
2. **库级值级 0.5/0.4（采纳）**：`rd_mined_materialize` 默认值 `_CORR_WARN 0.8→0.4`、
   `_CORR_REJECT 0.9→0.5`。对表 FactorMiner「与库相关 |ρ|<0.5 拒」；0.4 为预对齐警线。
   - 替换机制（T-FM-02）语义**不动**：单命中 + \|IC\| 条件成立仍可顶替；0.5 闸下多命中更常见 →
     `not_single_hit` 拒入（不能顶替一组相关簇，语义正确）。
   - CLI `--corr-threshold` / `--no-corr-gate` 保留，供审计与例外场景。
   - 历史判决不回滚（值不删既成事实）；审计给出「0.5 回溯模拟」的拦截面数字。
3. **结构原创闸（新）**：`factorminer/structure.py`
   - `profile(node)` → 算子路谱：前序 op 序列、shape_key（仅字面量抽象）、
     n-gram 多重集（n=1,2,3）、树深、节点数、算子种数。
   - `similarity(a, b)` → 分级：`clone`（AST 逐位相等）/ `literal_variant`（同 op 序列同特征、
     仅数字/窗口不同）/ `near`（trigram cosine ≥ θ）/ `novel`。
   - **硬拒政策 = 只拒 `clone`**。理由（有据取舍）：
     - `clone` 值必然重复，计算前拒零风险、纯省算力；
     - `literal_variant`（窗口/常数变体）**恰是 T-FE-09 变体残差台账要计算的对象**
       （「家族×窗口/变换变体」），预拒会掐死变体探索——此类交值级闸兜底（0.5 拒）；
     - `near(θ)` 只标注（未来生成循环的「饱和方向」输入，T-FM-04 接口）。
   - 审计证据（§5）决定 θ 与是否需要更严档；若未来算力预算需收紧，`screen()` 带 policy 参数预留。

## 5. 审计设计（离线只读，先行）

### A. 值级库审计（T-FM-03）→ `backend/scripts/audit_library_corr.py`

- 取样：近 120 交易日窗口内均匀抽 60 日（复用 `_pick_sample_days`，与物化器**同口径**）；
  逐日加载 CUSTOM `l1_factors` + `rd_mined` 分区，symbol 对齐。
- 逐日截面 rank（pairwise-complete，`min_periods=20`）→ 成对 Pearson（= Spearman）→ 对日平均
  （≥5 日重叠才记账）。列集 = l1（剔除 symbol/date）+ rd_mined 因子列。
- 输出三块（within-l1 / within-rd_mined / cross）：
  - \|ρ\| 分布：≥0.3/0.4/0.5/0.8/0.9 计数 + 平均成对 \|ρ\|（对表 FactorMiner A 股 0.30–0.31 标尺）；
  - top-20 高相关对明细；
  - **0.5 回溯模拟**：每个 rd_mined materialized 列 vs 其余全部列，≥0.5 命中列数分桶
    {0 命中 → 过；1 命中 → 可走替换裁决；≥2 → 多命中拒}，并出「若 0.5 闸回溯执行：留 X / 可替 Y / 拒 Z」。
  - 附 105 条历史 rejected_duplicate 的 |ρ| 分布（0.9 闸实际拦截面：median 0.986）。
- 报告：`/data/refs/factorminer/T-FM-03_library_corr_audit_{date}.{md,json}`。

### C. 执行结果落数（2026-10-11 收官）

**值级审计**（`T-FM-03_library_corr_audit_20261011.{md,json}`，脚本确定性复现）：
398 列（rd 119 / l1 273 / market 6）× 60 采样日全对——within-rd 平均 |ρ| 0.1584
（对照 FactorMiner A 股标尺 0.30–0.31；≥0.5 计 436 对、≥0.9 仅 1 对）；
rd↔l1 平均 0.1863（≥0.5 计 2130、≥0.9 计 37）；**0.5 回溯模拟**：119 个 rd 列
→ 8 零命中（照常可入）/ 20 单命中（可走 T-FM-02 替换裁决）/ 91 多命中拒（76.5%）；
历史 105 条 rejected_duplicate 记录 |ρ| min 0.9013 / median 0.9859 / max 1.0。

**闸缺陷修复（随审计同期提交）**：物化闸 `mean_rho_by_column`
（`statistical/incremental.py`）方差域错配——协方差与对照列方差取逐列对交集域、
新因子方差却取「任一对照列非空」宽域，对照列覆盖窄于 values 时（l1 只覆盖部分
标的、对照帧为全票并集）ρ 系统性缩水 √(k_pair/k_wide)。实测锚点
`rd_cci_20 × TDXGS_CCI_20` 真 ρ=0.9985 / 旧闸 0.7632（缩水比 0.773 ≈
√(3255/5511)）。修复 = 一律 pairwise-complete 原始和公式；pandas 逐日 pairwise
corr 金样对拍钉死（`test_statistical_incremental.py` 16 例，含稀疏覆盖列不复现
缩水的回归）。⇒ 存量高相关对与「0.5–0.9 灰区全放行」的解读修正为
「0.9 阈值宽容 + 缩水逃逸叠加」，历史判决不回滚；修复后闸复算锚点得 0.9985，
与本审计逐位一致（§3 回溯模拟即修复后闸的真实行为）。

**结构审计**（`T-FM-06_fm_structure_audit_20261011.{md,json}`）：5995 全对 →

**接线交叉验证**（落点 #7）：`import_paper_factors.py` 接入后对真报告逐条 screen，
