# QuantMind 模型训练完全指南（新人版）

> 本文档面向第一次使用模型训练中心的新人，说明每个模型的适用场景、优势、最佳特征搭配，以及训练时的实用建议。所有内容基于本系统（量化选股，横截面收益排序预测）的实际配置与实测。

---

## 一、先理解：我们在预测什么

**QuantMind 的模型任务**：对全市场股票的"未来 N 日收益排名"做预测（横截面排序）。

- 标签 = 未来 N 日收益的**截面排名**（每天所有股票从高到低排序）
- 模型输出 = 每只股票的**分数**（分数越高 = 预测未来涨得越好）
- 选股逻辑 = 买入分数最高的前 10-20%

**关键含义**：
1. 我们要的是**相对排序**（谁比谁强），不是精确收益数值
2. 所以模型评价看 **Rank IC**（预测排名 vs 实际排名的相关性），越高越好
3. 特征/标签都做**截面标准化**（每天每只股票与当天市场比较）

## 二、系统里的特征池（169 个特征）

训练时你会选择特征，它们分以下几类（前缀代表类别）：

| 前缀 | 类别 | 含义 | 典型特征 |
|------|------|------|---------|
| `mom_` | 动量 | 过去 N 日收益、乖离 | mom_ret_5d、mom_ret_20d、mom_ret_60d |
| `vol_` | 波动率 | 波动幅度、风险 | vol_std_20、vol_atr_14、vol_parkinson |
| `liq_` | 流动性 | 成交量、换手 | liq_volume、liq_amount、liq_turnover_os |
| `fun_` | 基本面 | 估值、盈利 | fun_pe、fun_pb、fun_roe、fun_peg |
| `style_` | 风格 | 市值、成长、价值 | style_ln_mv_total、style_bp、style_ep_ttm |
| `chip_` | 筹码 | 股东、持仓结构 | chip_*（筹码分布） |
| `tech_` | 技术指标 | KDJ/MACD/RSI 等 | tech_kdj、tech_macd、tech_rsi |
| `ind_` | 行业 | 申万行业 | ind_code_l1（类别特征）|
| `concept_` | 概念 | 题材概念 | concept_* |

## 三、模型逐一介绍

### 🎯 树模型（推荐入门首选，快且稳）

#### 1. LightGBM（首选基线）
- **特点**：直方图算法，训练极快，内存低，A 股选股 IC 最稳定
- **优势**：对动量、换手类因子的非线性捕捉好；与 XGBoost 异构，适合做集成
- **最佳特征**：动量 + 波动 + 流动性为主（mom_ret_*、vol_std_*、liq_turnover_*）
- **建议**：**第一个模型必跑它**，3 分钟内完成，作为其他模型的对照基准
- **典型参数**：learning_rate 0.02、num_leaves 31、min_child_samples 150、feature_fraction 0.7

#### 2. XGBoost
- **特点**：level-wise 分裂，与 LightGBM 互补
- **优势**：对资金流类因子（flow_vpin 等）捕捉略好；集成时与 LGB 互补性强
- **最佳特征**：LightGBM 基础 + 资金流/微结构特征
- **建议**：做 LGB 的**异构对照**，或与 LGB 一起做 Stacking 集成

#### 3. CatBoost
- **特点**：有序提升，类别特征原生支持
- **优势**：**开启"行业作为特征"（ind_code_l1）时优势最大**——原生处理类别特征，无需 one-hot
- **最佳特征**：务必勾选"行业编码作为特征"开关，配风格因子（style_bp 等）
- **建议**：想利用行业信息时用它；过拟合风险最低

#### 4. RandomForest（随机森林）
- **特点**：Bagging 思想，多树并行
- **优势**：作为 **Boosting 的对照基线**——若 RF 与 LGB 效果接近，说明信号主要是线性/低阶，无需深树；若 LGB 显著优于 RF，则非线性交互重要
- **最佳特征**：任意（不挑特征类型）
- **建议**：诊断用，帮助判断"值得投入复杂模型吗"

#### 5. Ridge（线性基线）
- **特点**：线性回归 + L2 正则
- **优势**：**sanity check 工具**——若 Ridge 的 IC > 0.03，说明特征有线性信号，树模型应更好；若 Ridge IC≈0 但树模型高，说明信号在非线性交互
- **最佳特征**：适合已做标准化的特征
- **建议**：必跑的诊断基线，**不用于实战**

### 🤖 深度学习模型（需要 GPU，耗时较长）

#### 6. GRU（推荐 DL 入门）
- **特点**：门控循环单元，捕捉时序依赖
- **优势**：DL 里性价比最高，训练快（约 10-20 分钟 GPU）
- **最佳特征**：**波动率时序衰减**类（vol_std_*、vol_parkinson_*），以及动量反转模式
- **建议**：DL 入门必跑；数据量 < 50 万行时慎用（易过拟合）

#### 7. LSTM
- **特点**：比 GRU 多门控，记忆更长
- **优势**：理论长程记忆更好，但 A 股实测 IC 提升有限（<5%）
- **最佳特征**：需要长历史窗口的因子
- **建议**：**GRU 效果好就不必试 LSTM**（实测提升有限且慢 40%）

#### 8. ALSTM（注意力 LSTM）
- **特点**：LSTM + 注意力机制
- **优势**：自动学习哪些时间步重要，捕捉**事件驱动**（业绩公告前后）
- **最佳特征**：事件型/基本面公告类特征
- **建议**：GRU 效果好（IC>0.05）再尝试；结果不稳定

#### 9. Transformer
- **特点**：自注意力，全局长程依赖
- **优势**：捕捉跨周期因子组合（短期动量 + 长期风格）
- **最佳特征**：需至少 100 万行数据收敛；适合多样特征组合
- **建议**：**数据量大才用**，否则容易欠拟合；参数量大，训练慢

#### 10. TabNet
- **特点**：表格数据专用 DL，自带特征选择（mask 机制）
- **优势**：**不需要时序窗口**（吃扁平特征），像"可学习的树模型"；不确定哪些因子有效时适合探索
- **最佳特征**：资金流（flow_*）、微结构因子
- **建议**：特征探索利器，但需预训练阶段，总时间约为 GRU 2 倍

#### 11. TCN（时间卷积网络）
- **特点**：因果卷积替代 RNN，训练快
- **优势**：比 GRU/LSTM 快约 50%；捕捉**波动率突变**（vol_jump）和**成交量异动**（liq_volume_ratio）
- **最佳特征**：vol_jump_zadj、liq_volume_ratio_*（异动类特征）
- **建议**：需要频繁重训模型时优先；kernel_size 可调（5→7 捕捉更长期依赖）

#### 12. NativeTFT（轻量 TFT）
- **特点**：GRU 时序编码 + 注意力 + 门控残差，QuantMind 自研
- **优势**：比 pytorch_forecasting TFT 轻 10 倍；GRU 效果好想加注意力时的选择
- **最佳特征**：动量 + 波动率的时序组合
- **建议**：GRU 效果好但想试注意力机制时用

#### 13. MLP（神经网络基线）
- **特点**：全连接网络，最简神经网络
- **优势**：**验证 RNN/Transformer 是否真优于全连接**——若 MLP 在扁平特征上 IC 已接近 GRU，说明时序结构不重要，直接用树模型
- **最佳特征**：任意扁平特征
- **建议**：DL 诊断基线，帮判断"时序建模是否值得"

## 四、新手训练推荐流程

### 阶段一：跑通基线（30 分钟）
1. **LightGBM**：默认参数 + 动量/波动/流动性特征 → 得到基准 Rank IC
2. **Ridge**：对照线性 IC（判断信号线性度）
3. **RandomForest**：对照 Bagging IC（判断 Boosting 价值）

### 阶段二：特征工程（关键，决定上限）
1. **多周期标签对比**：T+5 vs T+10 各跑一次，看哪个周期信号更强
2. **截面预处理开关**：开启"特征截面预处理"（标准化 + 缩尾）
3. **特征选择**：开 Optuna 超参搜索，或手动筛 IC 高的特征

### 阶段三：模型进阶
1. **XGBoost + LightGBM 集成**（Stacking）→ 通常比单模型 ICIR 提升 10-15%
2. **CatBoost + 行业特征** → 看行业信息增益
3. **GRU** → 看时序建模是否有额外增益
4. **对比**：模型管理页的 A/B 对比功能，看新模型是否真的更好

### 阶段四：验证上线
1. **看 test 集 ICIR**（模型管理页"生产监控"看真实 IC）
2. **软门禁**：test_rank_icir < 0.05 的模型保持候选态，人工评估后激活
3. **融合模型**：多周期（T+1/3/5/10）+ 多模型融合，选"生产IC动态"权重

## 五、关键参数速查

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 标签周期（T+N） | T+5 / T+10 | 短周期信号噪、长周期信号慢；A 股常用 T+5 |
| learning_rate | 0.01-0.03 | 太小慢、太大过拟合 |
| 特征数量 | 60-80（从 169 选）| 过多易过拟合 |
| 数据时间窗 | 训练 3-5 年 | 太短不充分、太长含旧结构 |
| 截面预处理 | 开启 | 标准化 + 缩尾，必开 |
| Optuna | 树模型开 20-30 次 | 自动调参，树模型值得 |

## 六、常见问题

**Q1：怎么判断模型好不好？**
看 **Rank ICIR**（Rank IC 均值/标准差）——> 0.2 可用，> 0.5 优秀。同时看**生产监控**的真实 IC（上线后每日回填）。

**Q2：DL 模型比树模型一定好吗？**
**不一定**。树模型在 A 股选股经常不输 DL。DL 的价值在捕捉时序依赖，但需要大数据和 GPU。先跑树模型，再用 DL 做增量验证。

**Q3：特征怎么选？**
先看特征管理里的 IC/ICIR 排序（系统自动算），选 IC 高且相关性低的。用"因子筛选"功能自动剔除弱/冗余特征。

筛选流水线（默认全开，可在训练请求的 `factor_selection` 里逐项关掉）：

1. **IC/ICIR 初筛**：|IC| ≥ 0.01 且 |ICIR| ≥ 0.15，不足时按 |IC|×|ICIR| 自适应回填；
2. **相关性 + 多样性剪枝**：两两 |ρ| < 0.9，且新增因子对集合的**有效因子数**（N_eff = exp(特征值熵)）增益 ≥ `dh_min_gain`（默认 0.1）——拦两两阈值看不见的多重共线；
3. **稳定性检验**：滚动 60 日 IC 波动 / |IC均值| < 2；
4. **PFS 扰动保真度**：截面 z 分加噪（高斯 + t 厚尾）后排名保真度 ≥ `pfs_threshold`（默认 0.9），排名一扰就塌的因子（多为并值/离散型）换成后续候选。

训练结果页的「因子筛选报告」会显示完整漏斗、每个因子的 PFS 与淘汰原因，以及入选集合「相当于几个独立因子」。想要数量优先可把 `pfs_enabled` / `dh_enabled` 设为 `false`，或调低 `pfs_threshold` / `dh_min_gain`。

**Q4：CPU 还是 GPU 训练？**
**训练用 GPU**（DL 模型必须），**推理用 CPU**（单日小样本，CPU 足够且稳定）。系统已自动配置。

**Q5：哪些市场能训练？**
CN（A股）/ HK（港股）/ US（美股）/ CRYPTO（区块链）/ FUTURES（期货）都支持，训练时选市场，系统自动用对应数据。
