## 1. 学习纪要（要点，按可用性排序）

### 1.1 FactorMiner（清华深研院+鹏城实验室，arXiv:2602.14670）

- **核心创新 = 经验记忆**（成功模式 + **禁区/负面知识**）：把「哪些方向已饱和」显式记住并注入下一轮生成（例：VWAP 偏离类 40+ 候选被毙 → 标记禁区）。消融：有记忆通过率 60% vs 无记忆 20%（效率 3 倍）。
- **四阶段验证**：IC≥0.04 → 与库相关 |ρ|<0.5 拒 → 批内去重 → 多市场鲁棒+OOS。
- **替换机制**：IC≥0.10 ∧ IC≥1.3×旧因子 ∧ 只与 1 个旧因子超阈 → **顶替**那个旧因子（库允许换代，而非只进不出）。
- 60+ 算子含**回归类（Slope/Rsquare/Resi）与条件类（IfElse）**——Alpha101 没有；实现「R² 高做趋势、低做回归」的自适应因子。
- 实测（10min K 线，CSI500）：Top-40 IC 8.25% / ICIR 0.77，等权组合 ICIR 1.29；跨市场（Crypto）IC 3.82% 不塌 —— 抓的是普适价量规律。
- 自带冷水：**10 分钟频**（日线表现未报告）、1 年训练 1 年测试（周期覆盖不足）——其 110 因子在我们日线场景**必须自测后才可采信**（见 T-FM-01）。

### 1.2 因子工程体系（窥市寻真，六年团队实践）

- **六维标签**（数据源/频率/家族/变换/目标/**成熟度**）是因子注册中心的最低元数据；莫让因子库变一锅粥。
- **正交化 = 增量闸**：新因子对库回归取残差 → 残差 IC_IR>0.3 才入库（施密特逐次；>500 因子换 PCA）。
- **八维单因子检验**：IC 正率 / 分层（等权+市值加权）/ 多空曲线形态 / **因子自相关**（定调仓频率）/ **中性化前后 IC 差>30% 说明靠市值行业吃饭** / **分市场状态 IC**（牛熊震荡）/ 换手率（>80% 单边扣费后可能净零）/ 衰减曲线。
- **Newey-West t**（IC 序列自相关修正）+ Bonferroni/FDR（我们已有 FDR）。
- **过拟合四形态**：经典/选择性（样本外选优也是过拟合）/**定义过拟合**（参数扫描取最优）/时代过拟合；三层防护含 **6 个月盲窗观察名单**（研究员看不到 OOS IC）。
- **复杂度惩罚**：复杂度 = 算子数 × log(参数搜索空间)；越复杂，IC_IR 门槛指数上升。
- **生命周期**：滚动 12m IC_IR<0.2 且连续 3 月未回升 → 退役（**降权不删**，权重 0 保留算力可重启用）；**拥挤度**（因子估值价差 top/bottom 组）是尾部风险预警。
- 自动挖掘定位：**广度探索**（已验证家族内扫参数/变换）+ 人工深度突破——与我们「统计派=广度、LLM 派=深度」的分工一致；警惕自动扩池的 FDR 膨胀。
- 五个实战坑：未来函数（财务**发布日**对齐）、幸存者偏差（退市股保留到退市日）、因子字典爆炸（命名规范）、回测窗口漂移（滚动**固定长度**窗）、忽略交易成本（报告**扣费后净 IC**）。

### 1.3 七大方法全览（叨客宁宁）

- 方法光谱：手工库 → GP → DL 端到端 → **GFlowNet**（生成概率正比奖励，天然多样性；reward=**市值中性化 |IC|**；与 PPO 的模式崩溃对比）→ **LLM 演化**（FTS：Macro 语义改写 + Micro Optuna，评估链 L1 IC≥0.01→L2 Sharpe≥0.5→L3 多重校正；UCT 父因子选择；**Experience Chain 失败模式聚类注入 prompt**）→ **多智能体联合优化**（RD-Agent-Quant，MAB 方向调度，已有开源）→ **K 因子有效前沿**（Ross 2026：**15 因子基数约束组合 OOS Sharpe 3.14 ≈ 158 因子稠密基准**；lasso 2.74——按「组合 Sharpe 贡献」选因子 ≠ 按 alpha 显著性选）。
- 关键结论：① 因子不在多而在精（**按组合边际贡献选，而非单因子显著性**）；② 多样性：池内相关 <0.3–0.4；③ 过拟合是头号杀手（样本内/样本外 IC 比 >3× 大概率过拟合）；④ **LLM 是辅助工具不是自主研究员**（FTS 实战 3 代熔断、97% 经典因子在期货已失效的案例）；⑤ 因子与模型应联合/should 互相塑造；⑥ **等权 1/N 是默认最优**（<1000 交易日别做复杂组合优化）。
- 个人路径推荐：经典库打底 + 最佳子集做减法 + GP 增量 + LLM 提效 + 严格 OOS 过滤——与我们"统计派（经典/系统化）打底 + RD-Agent（LLM）+ 滚动训练"的栈形不谋而合，缺的是「做减法」那一环。
