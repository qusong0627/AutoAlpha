# AutoAlpha 因子研究工作台

前端运行在 Windows，连接 WSL 中端口 8001 的独立因子挖掘后端。采用顶部主页面导航、居中容器内容、浅色蓝紫渐变；没有侧栏或折叠菜单。

## 启动与检查

```powershell
# 先启动 WSL 后端，再启动前端
wsl bash /mnt/d/git/autoalpha/scripts/wsl/start-dev.sh
D:\git\autoalpha\scripts\dev-web.cmd

cd D:\git\autoalpha\web
npm.cmd run typecheck
npm.cmd run build
powershell -File D:\git\autoalpha\scripts\web-smoke.ps1
```

开发地址为 `http://localhost:1688`。Vite 将 `/api` 和 `/health` 代理到独立后端。后端默认 `http://localhost:6789`，由 `VITE_API_URL` 覆盖。生产构建位于 `web/dist`；将其放在仓库的 `web/dist` 后，独立后端可在同一端口提供页面、静态资源、`/health` 和 `/api`，无需 Vite dev server。

## 主页面

| 路径 | 内容 |
| --- | --- |
| `/#/` | 后端真实任务/因子/物化概况、挖掘创建入口、最近任务、数据覆盖 |
| `/#/mine` | 算法能力驱动的参数表单、后端窗口预览、提交；AI 方向拆解与批量派发；文档输入 |
| `/#/tasks` | 数据库历史分页、状态筛选、实时进度、取消、日志、决策轨迹、按配置重跑 |
| `/#/factors` | 因子分页、任务/池/方向筛选、详情、代码下载、AI 解释、物化和回测/组合联动 |
| `/#/pool` | 质量/新颖度/面板概况、谱系图、清理建议、刷新、归档和恢复 |
| `/#/combos` | 具备面板的池内因子选择、组合权重优化、训练/验证指标、扣费净值 |
| `/#/backtest` | 单因子/批量验证、取消、台账、独立指标/成本口径、四类曲线、报告导出 |
| `/#/research` | 经典/私人研究快照、参考目录和真实排名、因子详情/对比/组合、报告/相关性/聚类/推荐组合 |
| `/#/data` | QuantDB 覆盖、物化回执、毕业桥、字段扫描、目录草稿、映射编辑、发布/克隆 |
| `/#/settings` | 模型状态、独立 Embedding 配置、默认参数、文档解析设置、环境检查 |

旧 `/#/me`、`/#/alpha-research`、`/#/factor-research` 路径保留重定向。

## 实现约定

- 新工作台代码集中在 `src/workspace/`，不修改镜像后端或上游仓库。
- `api.ts` 统一同域 HTTP、身份头、响应拆包与错误说明；`hooks.ts` 负责取消过期请求和串行轮询。
- 首页计数、因子指标、时间覆盖均取真实接口；缺失数值为 `—`，错误状态可以重试。
- 参数草稿和筛选保存于 sessionStorage；默认参数保存于 localStorage；模型密钥不写浏览器存储。
- 向量配置只提交变更字段。空 Key 表示保留原值，清除使用独立动作。
- 挖掘和回测先展示具体配置，再由用户提交。目录发布单独展示待发布版本和字段数。
- 图表分开显示净值、IC、分位与换手率，避免把不同单位画在同一坐标轴上。
- 页面按路由懒加载；曲线图组件按需加载。保留现有 React、Ant Design、ECharts 依赖。

## 当前部署边界

- 仅开放已验证的 A 股数据操作；其他市场的独立缓存需要另外核验。
- 文档挖掘关闭时显示未启用，不反复尝试上传。
- 研究/报告快照缺失时显示准备入口，参考目录不冒充真实计算结果。
- 训练数据源 `/sources` 目前有后端 500；页面保留其他可用区域，并提供错误重试。
- 训练模型、交易、推理和登录服务不属于这个独立后端，工作台不请求这些路由。
